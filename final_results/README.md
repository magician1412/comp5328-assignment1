This folder holds the results of the final experiment. It is kept outside `code/`, so it is not part of the submission archive.

These results supersede `final-sweep-v1` (commit `9c27214`). The only change is the Frobenius-NMF iteration cap, which was lowered from 3000 to 2000. ## Commands

The runs were started from the repository root and ran one after the other. `main.py` also writes the plots at the end of each run.

## Protocol

- **Frobenius-NMF:** tolerance stopping, tol = 1e-3 (ORL) / 5e-4 (YaleB), max_iter = 2000, min_iter = 200. Every run stopped by tolerance after 271–519 iterations.
- **RNMF-L1:** fixed 2000 iterations (tol = 0), λ = 0.01 (ORL) / 0.03 (YaleB).
- **Shared settings:** rank = number of classes; 5 repeats; 90% subsample.
- **Occlusion settings (b:m):** 4:0, 4:1, 8:1, 12:1, 16:1, 8:2, 8:3.
- **Seeds for repeat r:** subsample 100 + r, occlusion 200 + r, initialisation 300 + r. Both methods share the subsample, the occlusion and the initial W, H.
- **Standard deviations** are sample standard deviations over repeats (ddof = 1).

Each `metadata.json` records the full protocol.

## Contents

Each `<dataset>/` folder contains:
- `metadata.json`
- `raw_results.csv`
- `summary.csv`, which includes the paired difference `paired_rre_diff` = RRE(NMF) − RRE(RNMF-L1)
- `objective_trace.csv` (repeat 0)
- `plots/`:
  - `*_rre_sweeps.{png,pdf}`: RRE vs b with m = 1, and RRE vs m with b = 8
  - `*_objective.{png,pdf}`: objective vs iteration
  - `*_summary_table.tex`: the report's RRE table, which is `\input` by the LaTeX report

The `*_summary_table.tex` files and `acc_nmi_table.tex` were formatted by hand for the report and are not generated by `generate_plots.py`. Their values match `summary.csv`.

The per-setting reconstruction images show faces, so they are not archived here. They remain in the local run folders under `reconstructions/`.
